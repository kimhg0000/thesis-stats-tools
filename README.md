# 논문 통계 도구

https://kimhg0000.github.io/thesis-stats-tools/

논문 통계 분석을 직접 하는 대학원생을 위한 무료 한국어 계산기와 안내 글입니다. 값을 넣으면 결과와 함께 APA 7판 표기에 맞춘 결과 문장을 보여 줍니다.

- 통계 분석 방법 선택 도우미
- 효과크기 계산기 (Cohen's d, Hedges' g, 부분 η², d와 r 변환)
- 표본 크기·검정력 계산기 (t검정, 상관, 일원분산분석, 다중회귀)
- APA 결과 문장 생성기 (t, F, r, χ², 회귀계수)
- 크론바흐 알파 계산기 (문항 삭제 시 α 포함)
- 역채점·척도 점수 계산기
- 상관행렬 APA 표 만들기
- 매개효과 Sobel 검정과 몬테카를로 신뢰구간

정적 HTML, CSS, 자바스크립트만 씁니다. 입력한 자료는 브라우저 안에서만 계산되고 어디로도 전송되지 않습니다. 광고, 방문 추적, 외부 글꼴이 없습니다.

계산은 Python scipy, pingouin으로 구한 정답과 실제 브라우저에서 자동 대조해 검증했습니다. 오류를 발견하면 Issues에 남겨 주세요.

운영: 상담과연구
