홈 / 소개

소개와 검증 방법

이 사이트는 논문을 쓰는 대학원생이 통계 분석 결과를 스스로 이해하고 바르게 보고하도록 돕는 계산기와 글을 모아 둔 곳입니다. 분석을 대신하거나 논문을 대신 쓰는 곳이 아닙니다. 도구가 만든 문장은 출발점이니, 연구 맥락에 맞게 고쳐 쓰고 지도교수와 상의하세요.

운영자

크몽 판매자 "상담과연구"가 운영합니다. 크몽에서 논문 통계분석 서비스를 운영하고 있으며, 크몽 판매자 프로필에 공개된 이력은 다음과 같습니다.

  • 대학 상담센터 전임상담원 경력 3년
  • 교육학(교육상담) 전공
  • 자격: 청소년상담사 2급, 임상심리사 2급, 전문상담교사 2급, 직업상담사 2급

직접 하기 어려운 분석(구조방정식, 매개·조절, 잠재프로파일 등)은 크몽 서비스 페이지에서 문의할 수 있습니다.

개인정보와 입력 자료

회원 가입, 쿠키, 방문 추적 스크립트, 광고가 없습니다. 글꼴과 아이콘도 이 사이트 안에 두고 씁니다. 붙여 넣은 응답 자료와 입력한 값은 브라우저 안의 자바스크립트로만 계산되고 서버로 보내지지 않으며, 페이지를 닫으면 사라집니다. 방법 선택 도우미는 고른 답을 주소(URL) 뒤에 붙여 두는데, 이 역시 브라우저 안에만 남습니다. 사이트는 GitHub Pages에서 정적 파일로 제공되므로 GitHub가 일반적인 웹 서버로서 접속 기록을 남길 수 있습니다.

계산 검증

각 도구는 정답을 아는 시험 사례로 검증한 뒤 공개했습니다. 정답은 Python의 scipy, statsmodels, pingouin 패키지로 계산했고, 실제 브라우저(Playwright)로 이 사이트 화면에 값을 입력해 나온 결과를 정답과 자동으로 대조했습니다. 근사를 쓰는 곳(상관분석 표본 크기, 효과크기 신뢰구간, 몬테카를로 구간)은 해당 화면의 "계산 방법"에 근사임과 허용 오차를 적었습니다. 방법 선택 도우미는 선택 조합마다 기대하는 방법이 나오는지 자동 시험으로 확인합니다.

틀린 계산이나 설명을 발견하면 GitHub 저장소의 Issues에 남겨 주세요.
