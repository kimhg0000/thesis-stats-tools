대응표본 t검정 효과크기 Cohen's d 구하는 법

상담과연구, 2026-11-21

같은 사람을 프로그램 전후에 두 번 잰 자료라면 효과크기 d를 구하는 방법이 둘 이상 있고, 값이 크게 다를 수 있습니다. 무엇을 썼는지 밝히지 않으면 읽는 사람이 효과를 잘못 읽게 됩니다.

12명 예시

자기조절 프로그램 참여자 12명의 사전 점수는 M = 3.11(SD = 0.35), 사후 점수는 M = 3.44(SD = 0.41)입니다. 사후에서 사전을 뺀 차이 점수의 평균은 0.33, 표준편차는 0.15이고, 사전·사후 점수의 상관은 .93입니다. R 4.6.2의 t.test(paired = TRUE)로 분석하면 t(11) = 7.71, p < .001입니다.

표가 넓으면 옆으로 밀어 보세요.

효과크기나누는 값이 예의 값
dz = 차이 평균 / 차이 점수의 SD = t / √n0.152.23
dav = 차이 평균 / 두 시점 SD의 평균(0.35 + 0.41) / 20.88

같은 자료에서 2.23과 0.88이 나옵니다. 차이 점수의 표준편차는 두 시점의 상관이 높을수록 작아지기 때문에, 상관이 .93인 이 자료에서는 dz가 두 배 넘게 큽니다. 효과크기 계산기의 "t값" 탭에서 대응표본을 고르고 t = 7.71, n = 12를 넣으면 dz = 2.23이 나옵니다. dav는 두 시점의 평균과 표준편차로 직접 계산합니다.

어느 것을 쓰나

Lakens(2013)는 dz가 검정력 분석에는 맞지만, 독립집단 연구의 d와 나란히 비교하려면 dav처럼 원래 점수의 표준편차를 쓰는 값이 낫다고 정리했습니다. Dunlap 등(1996)은 메타분석에서 대응표본의 t값으로 독립집단 공식을 써 d를 구하면 효과를 과대추정한다고 지적했습니다. 학위논문이라면 둘 중 하나를 고르고, 식과 이름을 함께 적는 것으로 충분합니다. Cohen(1988)의 0.2, 0.5, 0.8 기준은 독립집단의 d를 염두에 둔 값이라 dz에 그대로 대지 않습니다.

논문에 쓰는 문장

"프로그램 참여 후 자기조절 점수(M = 3.44, SD = 0.41)는 참여 전(M = 3.11, SD = 0.35)보다 유의하게 높았다(t(11) = 7.71, p < .001). 효과크기는 두 시점 표준편차의 평균으로 나눈 dav = 0.88이었다(차이 점수의 표준편차로 나눈 dz = 2.23)."

흔한 실수

  • 대응표본의 t값을 독립표본 공식 d = t√(1/n₁ + 1/n₂)에 넣습니다. 이 예에서는 n₁ = n₂ = 12로 넣으면 3.15가 나옵니다.
  • dz = 2.23을 "매우 큰 효과"라고 쓰면서 어떤 d인지 밝히지 않습니다.
  • 통제집단 없는 사전·사후 설계의 효과를 프로그램 효과로 단정합니다. 시간 경과나 검사 반복의 효과가 섞여 있습니다.

참고문헌

  • Cohen, J. (1988). Statistical power analysis for the behavioral sciences (2nd ed.). Lawrence Erlbaum Associates.
  • Dunlap, W. P., Cortina, J. M., Vaslow, J. B., & Burke, M. J. (1996). Meta-analysis of experiments with matched groups or repeated measures designs. Psychological Methods, 1(2), 170–177.
  • Lakens, D. (2013). Calculating and reporting effect sizes to facilitate cumulative science: A practical primer for t-tests and ANOVAs. Frontiers in Psychology, 4, Article 863.

  • t검정 결과를 표와 문장으로 쓰는 법독립표본 t검정 결과를 APA 7판 형식의 표와 문장으로 옮기는 방법. 평균과 표준편차, 자유도, 정확한 p값, 효과크기 d, Welch 검정의 소수 자유도까지 다룹니다.
