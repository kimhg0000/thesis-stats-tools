회귀분석 표본 크기, G*Power에서 f² = 0.15로 구하는 법

상담과연구, 2026-11-21

G*Power에서 다중회귀 표본 크기를 구하려면 F tests 아래 "Linear multiple regression: Fixed model"을 고릅니다. 여기에 두 가지 메뉴가 있고, 어느 쪽을 고르느냐에 따라 같은 f²에서도 필요한 인원이 달라집니다(Faul et al., 2009).

표가 넓으면 옆으로 밀어 보세요.

검정하려는 것G*Power 메뉴예측변수 5개, f² = 0.15
모형 전체의 R²가 0보다 큰가R² deviation from zero92명
5개 중 1개가 더하는 설명력(여러 개면 그 수를 넣음)R² increase (tested predictors 1)55명

두 경우 모두 α = .05, 검정력 .80입니다. 표본 크기·검정력 계산기에서 다중회귀를 고르고 전체 예측변수 수 5, 검정하는 예측변수 수 5 또는 1을 넣으면 같은 값이 나옵니다. R 4.6.2로 비중심 F분포의 검정력을 표본 크기마다 계산해 같은 답을 확인했습니다.

f² = .15를 그대로 쓰면 안 되는 이유

0.15는 Cohen(1988)이 "중간"이라고 이름 붙인 관례값입니다. 연구 가설이 특정 변수 하나의 효과라면, 그 변수가 다른 변수를 통제하고 더하는 설명력은 대개 이보다 훨씬 작습니다. 같은 조건에서 f²를 0.02(Cohen의 "작은" 효과)로 바꾸면 필요한 인원은 55명에서 395명으로 늘어납니다. 그래서 선행연구의 R²나 ΔR²에서 f²를 계산해 근거로 씁니다. 전체 모형이면 f² = R² / (1 − R²), 일부 변수의 증가분이면 f² = ΔR² / (1 − 전체 모형의 R²)입니다.

경험칙과 함께 쓸 때

Green(1991)은 전체 모형 검정에 50 + 8m명, 개별 예측변수 검정에 104 + m명(m은 예측변수 수)이라는 경험칙을 검토했습니다. 예측변수가 5개면 각각 90명과 109명입니다. 이 경험칙은 효과크기를 중간 정도로 가정한 것이어서, 검정력 분석을 대신하기보다 결과가 비슷한지 대조하는 용도로 씁니다.

연구계획서 문장

"G*Power 3.1(Faul et al., 2009)로 표본 크기를 산출하였다. 예측변수 5개의 다중회귀분석에서 [선행연구]의 결과를 바탕으로 f² = 0.15를 가정하고, 유의수준 .05, 검정력 .80으로 계산한 결과 92명이 필요하였다. 응답 탈락률 15%를 고려하여 109명 이상을 모집할 계획이다."

탈락률을 반영할 때는 92 × 1.15가 아니라 92 / (1 − .15)로 계산해야 응답을 다 받은 뒤 92명이 남습니다. 92 / .85 = 108.2이므로 109명입니다.

흔한 실수

  • 예측변수 수에 더미변수와 상호작용항, 통제변수를 빠뜨립니다. 성별 더미 1개, 학년 더미 3개, 상호작용항 1개가 들어가면 모두 셉니다.
  • 매개·조절 분석의 표본 크기를 이 계산 하나로 대신합니다. 간접효과의 검정력은 따로 따져야 합니다.
