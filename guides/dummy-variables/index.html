더미변수를 만들고 회귀계수를 해석하는 법

상담과연구, 2026-11-15

전공계열을 인문 1, 사회 2, 공학 3으로 입력해 두고 그 열을 그대로 회귀분석에 넣으면 SPSS는 아무 경고 없이 계수를 하나 내놓습니다. 대학생 120명(계열별 40명)의 학습만족 자료로 해 보면 결과는 B = 0.02, p = .739, R² = .001입니다. 전공계열과 학습만족은 관계가 없어 보입니다.

같은 자료의 계열별 평균은 다음과 같습니다.

표가 넓으면 옆으로 밀어 보세요.

계열코드nM
인문1403.423
사회2403.058
공학3403.460

사회계열만 0.4점 가까이 낮습니다. 코드 1, 2, 3을 연속변수로 넣으면 "코드가 1 오를 때마다 평균이 일정하게 변한다"는 직선 하나를 강요하게 됩니다. 이 자료처럼 가운데 범주가 내려앉아 있으면 직선의 기울기는 0에 가까워지고 실제 차이는 사라집니다. 코드 번호에는 순서도 간격도 없으므로 이 계수는 해석할 대상이 아닙니다.

k−1개의 더미변수

범주가 k개면 0과 1로 된 변수를 k − 1개 만듭니다. 기준이 될 범주 하나는 변수를 만들지 않습니다. 인문계열을 기준으로 삼으면 다음과 같습니다.

표가 넓으면 옆으로 밀어 보세요.

계열D_사회D_공학
인문(기준)00
사회10
공학01

세 개를 모두 만들어 넣으면 세 변수의 합이 언제나 1이 되어 상수항과 완전히 겹칩니다. SPSS는 그중 하나를 자동으로 빼거나 계산을 멈춥니다. 더미변수는 한 묶음이므로 회귀식에 함께 넣고 함께 뺍니다. 위계적 회귀에서 한 단계에 D_사회만 넣고 D_공학은 다음 단계에 넣는 식으로 나누지 않습니다.

계수 읽기

D_사회와 D_공학을 넣은 결과는 다음과 같습니다(N = 120).

표가 넓으면 옆으로 밀어 보세요.

예측변수BSEtp
(상수)3.420.0746.15< .001
D_사회−0.370.10−3.48< .001
D_공학0.040.100.36.722

상수 3.42는 기준집단인 인문계열의 평균입니다. D_사회의 B = −0.37은 사회계열 평균이 인문계열보다 0.37점 낮다는 뜻이고(3.058 − 3.423), D_공학의 B = 0.04는 공학계열과 인문계열의 차이입니다. 모든 계수는 기준집단과의 비교입니다. 사회계열과 공학계열의 차이(0.40점)는 이 표 어디에도 없습니다. 그 비교가 필요하면 기준집단을 사회계열로 바꿔 한 번 더 돌리면 됩니다. 이 자료에서는 B = 0.40, p < .001로 나옵니다.

공변량(결과에 영향을 줄 수 있어 함께 통제하는 변수, 예를 들어 학년이나 성별)을 함께 넣으면 계수의 뜻이 "공변량이 같을 때의 차이"로 바뀝니다. 학년과 성별을 통제한 모형에서 D_사회의 B는 학년과 성별이 같은 두 학생을 비교했을 때 사회계열과 인문계열의 예측값 차이입니다.

범주 변수 전체가 의미 있는지는 개별 계수가 아니라 더미 묶음의 R² 변화량이나 F검정으로 봅니다. 위 예에서 두 더미를 넣은 모형은 R² = .133, F(2, 117) = 8.99, p < .001입니다. 1·2·3 코드를 넣었을 때의 .001과 비교해 보면 차이가 분명합니다.

기준집단은 어떻게 고르나

  • 연구문제의 비교 대상이 있으면 그 집단을 기준으로 둡니다. 프로그램 참여 유형을 비교한다면 미참여 집단이 기준이 됩니다.
  • 사례 수가 너무 적은 범주를 기준으로 두면 모든 계수의 표준오차가 커집니다. 큰 집단이나 대표 집단을 기준으로 둡니다.
  • "기타"처럼 뜻이 섞인 범주는 기준으로 두지 않습니다. 모든 계수가 "기타와 비교해"로 읽혀 해석할 수 없게 됩니다.

기준집단을 바꿔도 모형의 R², 예측값, 다른 예측변수의 계수는 그대로입니다.

SPSS와 jamovi에서 만들기

SPSS에서는 변환 메뉴의 "다른 변수로 코딩변경"으로 계열 변수에서 D_사회(사회=1, 나머지=0)와 D_공학(공학=1, 나머지=0)을 각각 만듭니다. 결측은 결측으로 남도록 "기타 모든 값"을 0으로 바꾸기 전에 결측값 처리를 먼저 지정합니다. jamovi의 선형회귀는 범주 변수를 Factors 칸에 넣으면 더미를 자동으로 만들고, Reference Levels 항목에서 기준집단을 고를 수 있습니다.

표준화 계수 β는 더미변수에서 해석이 어렵습니다. 0/1 변수의 표준편차는 집단 비율에 따라 달라지므로, 같은 평균 차이라도 집단 크기가 달라지면 β가 바뀝니다. 더미변수는 B로 해석하고 표에는 β를 적더라도 본문에서는 B를 씁니다(Cohen et al., 2003).

효과 코딩을 쓰는 경우

기준집단 대신 전체 평균과의 차이를 보고 싶다면 효과 코딩을 씁니다. 기준이 되는 범주에 0 대신 −1을 줍니다. 이때 각 계수는 해당 집단 평균이 집단 평균들의 평균(가중하지 않은 평균)과 얼마나 다른지를 뜻합니다(Cohen et al., 2003). 비교할 기준집단이 따로 없을 때 쓸 만하지만, 국내 학위논문에서는 더미 코딩이 훨씬 흔하므로 효과 코딩을 썼다면 코딩 방식을 표 주석에 밝힙니다.

논문에 쓰는 문장

"전공계열은 인문계열을 기준집단으로 하는 두 개의 더미변수로 변환하여 투입하였다. 분석 결과, 사회계열 학생의 학습만족은 인문계열보다 0.37점 낮았으나(B = −0.37, SE = 0.10, t(117) = −3.48, p < .001), 공학계열과 인문계열의 차이는 통계적으로 유의하지 않았다(B = 0.04, SE = 0.10, t(117) = 0.36, p = .722)."
