SPSS 출력의 숫자를 논문 문장과 APA 표로 바꿉니다

논문 통계를 직접 하는 대학원생을 위한 무료 계산기입니다. 가입이 필요 없고, 입력한 자료는 이 브라우저 밖으로 나가지 않습니다.

SPSS 출력에서 옮긴 값
t2.45
자유도58
평균(참여 / 비참여)3.62 / 3.18
표준편차0.71 / 0.68
논문에 쓰는 문장APA 결과 문장 생성기 열기

프로그램 참여 집단(M = 3.62, SD = 0.71)과 비참여 집단(M = 3.18, SD = 0.68)의 학습몰입 차이는 통계적으로 유의하였다(t(58) = 2.45, p = .017, d = 0.63).

도구

  • 크론바흐 알파 계산기
    넣는 것
    엑셀에서 복사한 한 척도의 문항 응답
    받는 것
    Cronbach's α, 문항 삭제 시 α, 문항-총점 상관, 논문 문장
  • 상관행렬 APA 표 만들기
    넣는 것
    엑셀에서 복사한 변수별 점수(척도 평균 등)
    받는 것
    M, SD, r과 * 표시가 있는 APA 상관표, 본문 문장
  • APA 결과 문장 생성기
    넣는 것
    SPSS 출력의 t, F, r, χ², 회귀계수와 자유도
    받는 것
    p값 재계산, APA 7판 한국어 결과 문장, 표 머리
  • 효과크기 계산기
    넣는 것
    두 집단의 평균·표준편차·사례 수, 또는 t값, F값
    받는 것
    Cohen's d와 95% 신뢰구간, Hedges' g, 부분 η², d와 r 변환
  • 통계 분석 방법 선택 도우미
    넣는 것
    연구 질문, 변수 유형, 자료 구조(서너 번 고르기)
    받는 것
    분석 방법, 자료 조건, 보고 지표, 흔한 실수, 맞는 도구
  • 표본 크기·검정력 계산기
    넣는 것
    분석 종류, 예상 효과크기, 유의수준, 검정력
    받는 것
    필요한 최소 표본 수, 탈락률 반영 인원, 연구방법 문장
  • 역채점·척도 점수 계산기
    넣는 것
    엑셀에서 복사한 리커트 응답(머리글 포함)
    받는 것
    역채점한 값과 척도 합계·평균 열, 엑셀에 다시 붙일 표
  • 매개효과 Sobel 검정·간접효과 신뢰구간
    넣는 것
    경로계수 a, b와 각각의 표준오차
    받는 것
    간접효과 ab, Sobel 계열 검정, 몬테카를로 95% 신뢰구간, 논문 문장

안내 글

신뢰도와 척도 점수

  • 크론바흐 알파가 .60대일 때 논문에 쓰는 법신뢰도 계수가 .70에 못 미칠 때 먼저 점검할 것과, 연구방법과 연구의 한계에 정직하게 적는 문장 예시를 정리했습니다.
  • 역문항 처리와 척도 점수, 합계와 평균 중 무엇을 쓰나역채점 공식, 역문항을 찾는 방법, 합계 점수와 평균 점수의 차이, 결측 응답 처리 규칙을 연구방법에 적는 법을 정리했습니다.

결과를 표와 문장으로 쓰기

  • t검정 결과를 표와 문장으로 쓰는 법독립표본 t검정 결과를 APA 7판 형식의 표와 문장으로 옮기는 방법. 평균과 표준편차, 자유도, 정확한 p값, 효과크기 d, Welch 검정의 소수 자유도까지 다룹니다.
  • 상관분석 결과를 APA 표로 만드는 법APA 7판 형식의 상관표 구성(변수 번호, 평균과 표준편차, 아래 삼각형, 유의 표시 주석)과 본문 문장 쓰는 법을 예시로 정리했습니다.
  • 회귀분석 결과표에 B, SE, β를 어떻게 쓰나다중회귀분석 결과표의 열 구성(B, SE, β, t, p), 모형 적합도(R², 수정된 R², F) 보고, 계수 해석과 '영향' 표현의 주의점을 예시로 정리했습니다.
  • 효과크기 d, η², r 어떻게 읽고 보고하나Cohen의 d, 에타제곱(η²)과 부분 에타제곱, 상관계수 r의 해석 기준과 그 한계, Hedges' g 보정, 신뢰구간과 함께 보고하는 방법을 정리했습니다.

연구 설계와 분석 선택

  • 연구방법에 표본 크기 근거를 쓰는 법사전 검정력 분석으로 표본 크기를 정하고 연구방법에 적는 방법. 효과크기 근거, 검정력 .80, G*Power 인용, Green(1991)의 경험칙, 탈락률 보정, 사후 검정력의 문제를 다룹니다.
  • 표본이 작을 때 쓸 수 있는 분석집단당 10~20명 정도의 작은 표본에서 쓸 수 있는 비모수 검정, Fisher 정확검정, 효과크기와 신뢰구간 보고, 피해야 할 분석과 한계 기술 방법을 정리했습니다.
  • 정규성 검정, 왜도·첨도 기준은 무엇을 적나Shapiro-Wilk 검정이 큰 표본에서 쉽게 유의해지는 이유, West 등(1995)과 Kline(2016)의 왜도·첨도 기준, 집단별·잔차 기준 점검, 연구방법에 쓰는 문장을 정리했습니다.

매개효과, 구조방정식, 잠재프로파일

  • 매개효과 검증, Sobel 검정보다 부트스트랩을 권하는 이유Baron과 Kenny의 단계 검증, Sobel 검정, 부트스트랩 신뢰구간, 몬테카를로 신뢰구간의 차이와 간접효과를 논문에 보고하는 형식을 정리했습니다.
  • 구조방정식 적합도 지수를 논문에 쓰는 법구조방정식모형의 χ², CFI, TLI, RMSEA(90% 신뢰구간), SRMR을 보고하는 방법과 Hu와 Bentler(1999) 등 기준값의 출처와 한계를 정리했습니다.
  • 집단 비교 전에 측정동일성을 확인하는 이유와 방법남녀나 학년 집단의 잠재평균이나 경로를 비교하기 전에 형태, 측정(부하량), 절편 동일성을 차례로 검증하는 방법과 ΔCFI·ΔRMSEA 기준, 부분 동일성 처리를 정리했습니다.
  • 잠재프로파일분석에서 프로파일 수를 정하는 법잠재프로파일분석에서 AIC, BIC, SABIC, LMR-LRT, BLRT, 엔트로피, 최소 집단 크기를 함께 보고 프로파일 수를 정하고 적합도 표를 쓰는 방법을 예시로 정리했습니다.
  • 군집분석과 잠재프로파일분석 중 무엇을 쓸까K-평균·위계적 군집분석과 잠재프로파일분석의 차이(집단 수 결정, 소속 방식, 표본 크기, 가정)와 각각이 맞는 연구 상황을 정리했습니다.

직접 하기 어려운 분석(구조방정식, 매개·조절, 잠재프로파일 등)은 크몽에서 도와드립니다.운영: 상담과연구, 대학 상담센터 전임상담원 경력 3년, 교육학(교육상담) 전공

운영: 상담과연구. 개인정보를 수집하지 않으며, 도구에 입력한 자료는 브라우저 안에서만 계산되고 어디로도 전송되지 않습니다. 광고와 방문 추적 스크립트가 없습니다.
