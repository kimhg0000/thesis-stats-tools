문항 삭제 시 α가 전체 α보다 높다고 바로 문항을 지우지는 않습니다. 문항 내용이 구성개념을 대표하는지, 원척도에서 그 문항이 어떻게 쓰였는지를 함께 봅니다.

계산 방법과 근거

문항 수를 k, 문항 i의 분산을 si², 문항 합계의 분산을 sX²라 할 때 다음 식을 씁니다. 분산은 n − 1로 나눈 표본분산입니다.

α=k−1k​(1−sX2​∑i=1k​si2​​)

문항 삭제 시 α는 해당 문항을 빼고 남은 k − 1개 문항으로 같은 식을 다시 계산한 값이고, 수정된 문항-총점 상관은 그 문항과 나머지 문항 합계의 상관입니다. 결과는 Python pingouin 패키지의 cronbach_alpha 함수와 대조해 시험했습니다.
