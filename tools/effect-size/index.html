효과크기 계산기

가진 값에 맞는 칸 하나만 채우면 됩니다. SPSS 출력에 효과크기가 없을 때, 선행연구의 t나 F로 효과크기를 추정할 때 씁니다.

1. 두 독립집단의 평균과 표준편차로

Cohen's d (합동 표준편차 기준)
d의 95% 신뢰구간 (근사)
Hedges' g (소표본 보정)
r로 환산 (집단 소속 0/1과 점수의 상관, 점이연 상관)
합동 표준편차 (두 집단 표준편차를 사례 수로 가중해 합친 값)

논문에 쓰는 문장

2. t값으로

Cohen's d
r = √(t² / (t² + df))

3. 분산분석 F값으로

부분 η² (η²p)
Cohen's f

η²p = F × df₁ / (F × df₁ + df₂). 일원분산분석에서는 η²와 같고, 요인이 둘 이상이면 η²보다 크거나 같습니다.

4. d와 r 서로 바꾸기

두 집단 크기가 같다고 가정한 식입니다: r = d / √(d² + 4), d = 2r / √(1 − r²). 집단 크기를 알면 1번 칸을 쓰세요.

해석 기준과 계산식

Cohen(1988)이 제시한 관례적 기준은 d 0.20(작음), 0.50(중간), 0.80(큼), r .10, .30, .50, η² .01, .06, .14, f 0.10, 0.25, 0.40입니다. η² 기준은 일원분산분석을 염두에 둔 값이라, 요인이 여럿인 설계의 부분 η²에 그대로 대면 효과를 크게 읽게 됩니다. 대응표본의 dz에도 d 기준을 그대로 대지 않습니다. Cohen 자신도 이 기준은 해당 분야의 기준이 없을 때 쓰는 대략적인 값이라고 밝혔습니다. 같은 분야 선행연구의 효과크기와 비교하는 해석이 더 낫습니다.

d = (M1 − M2) / Sp, Sp = √[((n1 − 1)s1² + (n2 − 1)s2²) / (n1 + n2 − 2)] g = d × (1 − 3 / (4(n1 + n2) − 9)) SE(d) = √[(n1 + n2)/(n1·n2) + d² / (2(n1 + n2))], 95% CI = d ± t(.975, n1 + n2 − 2) × SE r = d / √(d² + (N² − 2N)/(n1·n2)), N = n1 + n2 t → d (독립) = t × √(1/n1 + 1/n2), t → dz (대응) = t / √n

신뢰구간은 Hedges와 Olkin(1985)의 근사 표준오차에 자유도 n₁ + n₂ − 2인 t 임계값을 곱한 값으로, Python pingouin의 compute_esci와 같은 방식입니다. 임계값으로 z(1.96)를 쓰는 프로그램이나 비중심 t분포로 정확한 구간을 구하는 프로그램(JASP 등)과는 소수 둘째 자리에서 차이가 날 수 있습니다. 모든 결과는 pingouin과 대조해 시험했습니다.
