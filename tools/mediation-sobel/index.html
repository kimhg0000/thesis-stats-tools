세 방법은 간접효과의 표준오차를 구하는 식만 조금 다릅니다(아래 계산 방법).

원자료가 있다면 부트스트랩 신뢰구간(SPSS·SAS의 PROCESS macro, R의 lavaan 등, 보통 5,000회 이상)이 표준입니다. Sobel 검정은 ab의 표집분포를 정규분포로 가정하는데 실제로는 치우쳐 있어 검정력이 낮습니다. 이 화면의 몬테카를로 구간은 계수와 표준오차만 있을 때 쓰는 대안입니다(Preacher & Selig, 2012).

계산 방법과 근거

Sobel: SE = √(b²·sa² + a²·sb²) Aroian: SE = √(b²·sa² + a²·sb² + sa²·sb²) Goodman: SE = √(b²·sa² + a²·sb² − sa²·sb²) z = ab / SE, p = 2 × (1 − Φ(|z|))

몬테카를로 구간은 a ~ N(a, sa²), b ~ N(b, sb²)에서 서로 독립으로 1,000,000번 뽑아 곱한 값의 2.5, 97.5 백분위수입니다. 같은 입력이면 같은 결과가 나오도록 난수 씨앗을 입력값으로 고정합니다. 단순매개모형에서 a와 b의 추정치는 서로 상관이 없으므로 독립 추출을 씁니다. Sobel 계열 값은 Python으로 계산한 값과, 몬테카를로 구간은 Python numpy로 4,000,000번 뽑은 구간과 비교해 차이가 Sobel 표준오차의 1% 이내인지 시험했습니다.
