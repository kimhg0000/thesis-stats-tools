기본은 목록별 제외(빈 칸이 하나라도 있는 응답자를 모든 계산에서 뺌)입니다. 쌍별 제외는 변수 쌍마다 두 값이 모두 있는 응답자만 써서, 칸마다 사례 수가 다를 수 있습니다.

계산 방법과 근거

Pearson 상관계수 r을 구하고 자유도 n − 2인 t분포로 양측 p를 계산합니다. 평균과 표준편차(n − 1로 나눈 표본표준편차)는 상관 계산에 쓴 응답자로 구합니다. 결과는 Python scipy.stats.pearsonr과 대조해 시험했습니다.

t=1−r2​rn−2​​,df=n−2

이어서 쓸 도구

  • APA 결과 문장 생성기특정 상관 하나를 문장으로 다듬을 때
  • 통계 분석 방법 선택 도우미상관 다음 단계(회귀, 매개, 구조방정식) 고르기
  • 크론바흐 알파 계산기각 척도의 신뢰도 확인

함께 읽을 글

  • 상관분석 결과를 APA 표로 만드는 법

직접 하기 어려운 분석(구조방정식, 매개·조절, 잠재프로파일 등)은 크몽에서 도와드립니다.운영: 상담과연구, 대학 상담센터 전임상담원 경력 3년, 교육학(교육상담) 전공

개인정보를 수집하지 않으며, 도구에 입력한 자료는 브라우저 안에서만 계산되고 어디로도 전송되지 않습니다. 광고와 방문 추적 스크립트가 없습니다.
