계산 방법과 근거

t검정, 분산분석, 회귀는 G*Power 3.1(Faul et al., 2007, 2009)과 같은 비중심 F분포로 검정력을 계산하고, 목표 검정력에 처음 도달하는 표본 수를 찾습니다. 양측 t검정은 t² = F(1, df)이므로 같은 방식으로 정확히 계산됩니다.

독립 t검정: df = 2n − 2, λ = d² · n / 2 (n: 집단별 사례 수) 대응·일표본: df = n − 1, λ = d² · n 일원분산분석: df1 = k − 1, df2 = N − k, λ = f² · N 다중회귀: df1 = q, df2 = N − p − 1, λ = f² · N R² 검정: f² = R² / (1 − R²), R² 증가량 검정: f² = ΔR² / (1 − R²전체) 검정력 = P( F'(df1, df2, λ) > F 임계값 )

상관분석은 Fisher의 z 변환을 쓰는 근사식 N = ((z1−α/2 + z1−β) / C)² + 3, C = ½ ln((1 + r)/(1 − r))을 씁니다. 근사이므로 G*Power의 정확 계산(이변량 정규분포)과 1~2명 차이가 날 수 있습니다. 예를 들어 r = .30, α = .05, 검정력 .80에서 이 식은 85명, G*Power 정확 계산은 84명을 줍니다.

비중심 F분포 계산은 Python scipy.stats.ncf와 대조해 검정력이 소수 넷째 자리까지, 필요 표본 수가 정확히 일치하는지 시험했습니다.
